# Схема подключения — Oiynup Device

## Почему INMP441 лучше MAX9814+MCP3008

| | MAX9814 + MCP3008 | INMP441 |
|---|---|---|
| Тип сигнала | Аналог → SPI АЦП | Цифровой I2S |
| Проводов | 8 проводов | 5 проводов |
| Качество | 10-бит, 8kHz | 24-бит, до 32kHz |
| Дополнительные чипы | MCP3008 | не нужны |
| Совместимость с RPi | Через SPI | Нативный I2S |

## Итоговое распределение GPIO

```
Raspberry Pi Zero 2 W — 40-pin header

       3.3V  [ 1] [ 2] 5V
      GPIO2  [ 3] [ 4] 5V
      GPIO3  [ 5] [ 6] GND
      GPIO4  [ 7] [ 8] GPIO14 (TXD) ──────────────→ SIM900 RXD
        GND  [ 9] [10] GPIO15 (RXD) ←────────────── SIM900 TXD
     GPIO17  [11] [12] GPIO18 (PCM_CLK) ─────┬────→ MAX98357 BCLK
     GPIO27  [13] [14] GND                   └────→ INMP441 SCK
     GPIO22  [15] [16] GPIO23
      3.3V   [17] [18] GPIO24
     GPIO10  [19] [20] GND
      GPIO9  [21] [22] GPIO25
     GPIO11  [23] [24] GPIO8
        GND  [25] [26] GPIO7
      GPIO0  [27] [28] GPIO1
      GPIO5  [29] [30] GND
      GPIO6  [31] [32] GPIO12
GPIO13 PWM1  [33] [34] GND
GPIO19 LRCLK [35] [36] GPIO16   GPIO19 ──────┬────→ MAX98357 LRC
     GPIO26  [37] [38] GPIO20   GPIO20 ←──── INMP441 SD
        GND  [39] [40] GPIO21   GPIO21 ──────────→ MAX98357 DIN
                                               └────→ INMP441 WS (GPIO19)
```

**Использованные GPIO:**

| GPIO | Пин | Функция | Модуль |
|------|-----|---------|--------|
| GPIO13 | 33 | PWM1 | WS2812B DIN |
| GPIO14 | 8  | UART TX | SIM900 RXD |
| GPIO15 | 10 | UART RX | SIM900 TXD |
| GPIO17 | 11 | Output  | SIM900 RST |
| GPIO18 | 12 | PCM_CLK | MAX98357 BCLK **и** INMP441 SCK |
| GPIO19 | 35 | PCM_FS  | MAX98357 LRC **и** INMP441 WS |
| GPIO20 | 38 | PCM_DIN | INMP441 SD (данные от микрофона) |
| GPIO21 | 40 | PCM_DOUT | MAX98357 DIN (данные к усилителю) |

> 💡 **GPIO18 и GPIO19 используют оба устройства одновременно** — это нормально.
> I2S — шинный протокол. CLK и WS общие, а DATA раздельные (IN и OUT).

## МОДУЛЬ 2 — INMP441 (I2S микрофон)

```
                    ┌───────────────────────────────┐
                    │           INMP441             │
RPi 3.3V (пин 1) ──┤ VDD                           │
       GND (пин 6)──┤ GND                           │
RPi GPIO20 (пин38)──┤ SD   (Serial Data — выход)    │
RPi GPIO18 (пин12)──┤ SCK  (Clock — вход)           │
RPi GPIO19 (пин35)──┤ WS   (Word Select — вход)     │
       GND (пин 6)──┤ L/R  (GND = левый канал)      │
                    └───────────────────────────────┘
```

| Провод | INMP441 | RPi | Пин RPi |
|--------|---------|-----|---------|
| 🔴 Красный | VDD | 3.3V | Пин 1 |
| ⚫ Чёрный | GND | GND | Пин 6 |
| 🟡 Жёлтый | SD | GPIO20 (PCM_DIN) | Пин 38 |
| 🟠 Оранжевый | SCK | GPIO18 (PCM_CLK) | Пин 12 |
| 🔵 Синий | WS | GPIO19 (PCM_FS) | Пин 35 |
| ⚫ Чёрный | L/R | GND | Пин 9 |

> **L/R пин:** GND = левый канал, 3.3V = правый канал.
> Подключи к GND — будем читать левый канал.

> **SCK и WS** уже подключены к MAX98357. Просто соединяй вторым проводом
> на те же пины RPi — параллельное подключение, ничего не сгорит.

## МОДУЛЬ 3 — MAX98357 (I2S усилитель → динамик)

```
                    ┌──────────────────────────────────┐
                    │            MAX98357              │
RPi 3.3V (пин 1) ──┤ VIN                              │
       GND (пин39)──┤ GND                              │
RPi GPIO21 (пин40)──┤ DIN   (данные от RPi)            │
RPi GPIO18 (пин12)──┤ BCLK  (тактовый)                 │
RPi GPIO19 (пин35)──┤ LRC   (left/right select)        │
                    │ SD  ── не подключать (моно)      │
                    │ GAIN── GND → усиление 9dB        │
                    │                                  │
                    │ OUT+ ─────────────────→ Динамик+ │
                    │ OUT- ─────────────────→ Динамик- │
                    └──────────────────────────────────┘
```

| Провод | MAX98357 | RPi | Пин RPi |
|--------|---------|-----|---------|
| 🔴 Красный | VIN | 3.3V | Пин 1 |
| ⚫ Чёрный | GND | GND | Пин 39 |
| 🟡 Жёлтый | BCLK | GPIO18 (PCM_CLK) | Пин 12 |
| 🔵 Синий | LRC | GPIO19 (PCM_FS) | Пин 35 |
| 🟠 Оранжевый | DIN | GPIO21 (PCM_DOUT) | Пин 40 |
| — | SD | Не подключать | — |
| — | GAIN | GND | — |

**Динамик:** любой 4–8 Ом до 3 Вт, к OUT+ и OUT−.

## МОДУЛЬ 4 — SIM900 GSM/GPRS

```
                    ┌───────────────────────────────────┐
                    │              SIM900               │
 RPi GPIO14 (пин8)──┤ RXD  (RPi TX → SIM900 RX)        │
RPi GPIO15 (пин10)──┤ TXD  (SIM900 TX → RPi RX)        │
RPi GPIO17 (пин11)──┤ RST  (программный сброс)          │
       GND ─────────┤ GND  (общая земля с RPi и БП!)    │
  Внешний БП 5V ────┤ VCC  (НЕ от RPi! Отдельный БП)   │
                    │ SIM-карта — вставить в слот        │
                    └───────────────────────────────────┘
```

| Провод | SIM900 | Откуда |
|--------|--------|--------|
| 🔴 Красный | VCC | Внешний БП **5V / 2A** |
| ⚫ Чёрный | GND | Общая земля (и RPi, и БП) |
| 🟠 Оранжевый | RXD | GPIO14 RPi (пин 8) |
| 🟡 Жёлтый | TXD | GPIO15 RPi (пин 10) |
| 🔵 Синий | RST | GPIO17 RPi (пин 11) |

> ⚠️ **КРИТИЧНО:** SIM900 потребляет до **2А** при отправке SMS.
> Подключи от отдельного БП. Земля — общая с RPi.

## МОДУЛЬ 5 — WS2812B RGB матрица

```
                    ┌──────────────────────────────────┐
                    │         WS2812B Matrix           │
  Внешний БП 5V ────┤ VCC                              │
       GND ─────────┤ GND (общая земля!)               │
RPi GPIO13 (пин33)──┤ DIN ← [резистор 300 Ом]          │
                    └──────────────────────────────────┘
```

| Провод | WS2812B | Откуда |
|--------|---------|--------|
| 🔴 Красный | VCC | Внешний БП 5V |
| ⚫ Чёрный | GND | Общая земля |
| 🟢 Зелёный | DIN | GPIO13 (пин 33) через **резистор 300 Ом** |

> Резистор 300 Ом — в разрыв провода DIN, прямо у матрицы.

## Общая схема питания

```
┌──────────────────────────────────────────────┐
│           Блок питания 5V / 3A               │
└───┬───────────────────────────┬──────────────┘
    │                           │
    ↓ (через microUSB)          │
 RPi Zero 2 W              Распределитель
    │                           │
    │ 3.3V (внутренний)    ┌────┴────┐
    ├──→ INMP441 VDD       ↓        ↓
    ├──→ MAX98357 VIN    SIM900   WS2812B
    └──→ (Camera — встроено)

GND всех устройств → единая шина GND
```
