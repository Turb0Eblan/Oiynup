## Физическая карта 40-pin разъёма RPi

```
                    ┌───────────────┐
              3.3V  │  1 ●   ● 2   │  5V
   (FREE) I2C SDA   │  3 ○   ● 4   │  5V
   (FREE) I2C SCL   │  5 ○   ● 6   │  GND  → INMP441 GND, L/R
              GPIO4 │  7 ○   ● 8   │  GPIO14 (TX) → SIM900 RXD
              GND   │  9 ●   ● 10  │  GPIO15 (RX) ← SIM900 TXD
GPIO17 → SIM900 RST │ 11 ●   ● 12  │  GPIO18 (CLK) → MAX98357 BCLK + INMP441 SCK
             GPIO27 │ 13 ○   ● 14  │  GND
             GPIO22 │ 15 ○   ○ 16  │  GPIO23
              3.3V  │ 17 ●   ○ 18  │  GPIO24
             GPIO10 │ 19 ○   ● 20  │  GND
              GPIO9 │ 21 ○   ○ 22  │  GPIO25
             GPIO11 │ 23 ○   ○ 24  │  GPIO8
              GND   │ 25 ●   ○ 26  │  GPIO7
              GPIO0 │ 27 ○   ○ 28  │  GPIO1
              GPIO5 │ 29 ○   ● 30  │  GND
              GPIO6 │ 31 ○   ○ 32  │  GPIO12
GPIO13 → WS2812 DIN │ 33 ●   ● 34  │  GND
GPIO19 → LRC + WS   │ 35 ●   ○ 36  │  GPIO16
             GPIO26 │ 37 ○   ● 38  │  GPIO20 ← INMP441 SD
              GND   │ 39 ●   ● 40  │  GPIO21 → MAX98357 DIN
                    └───────────────┘
● = используется    ○ = свободен
```

### 🎤 INMP441 — I2S микрофон
| INMP441 | RPi Пин | GPIO | Примечание |
|---------|---------|------|------------|
| VDD | 1 | 3.3V | Питание |
| GND | 6 | GND | Земля |
| L/R | 6 | GND | GND = левый канал |
| SD | 38 | GPIO20 | Данные → RPi (PCM_DIN) |
| SCK | 12 | GPIO18 | Тактовый ← RPi (общий с MAX98357) |
| WS | 35 | GPIO19 | Word Select ← RPi (общий с MAX98357) |

---

### 🔊 MAX98357 — I2S усилитель
| MAX98357 | RPi Пин | GPIO | Примечание |
|----------|---------|------|------------|
| VIN | 1 | 3.3V | Питание |
| GND | 39 | GND | Земля |
| BCLK | 12 | GPIO18 | Тактовый ← RPi (общий с INMP441) |
| LRC | 35 | GPIO19 | Word Select ← RPi (общий с INMP441) |
| DIN | 40 | GPIO21 | Данные ← RPi (PCM_DOUT) |
| SD | — | — | Не подключать |
| GAIN | GND | — | GND = усиление 9dB |
| OUT+ | — | — | → Динамик (+) |
| OUT− | — | — | → Динамик (−) |

---

### 📡 SIM900 — GSM/GPRS
| SIM900 | RPi Пин | GPIO | Примечание |
|--------|---------|------|------------|
| VCC | — | — | ⚠️ Внешний БП 5V/2A (не от RPi!) |
| GND | Общий | — | Общая земля с RPi и БП |
| RXD | 8 | GPIO14 | ← RPi TX |
| TXD | 10 | GPIO15 | → RPi RX |
| RST | 11 | GPIO17 | Программный сброс |

---

### 💡 WS2812B — RGB матрица
| WS2812B | RPi Пин | GPIO | Примечание |
|---------|---------|------|------------|
| VCC | — | — | Внешний БП 5V |
| GND | Общий | — | Общая земля |
| DIN | 33 | GPIO13 | Через резистор **300 Ом** |

## Питание

| Устройство | Напряжение | Ток (макс) | Источник |
|-----------|------------|-----------|---------|
| RPi Zero 2 W | 5V | 1.2A | Внешний БП (microUSB) |
| INMP441 | 3.3V | 1 мА | От RPi (пин 1) |
| MAX98357 | 3.3V | 80 мА | От RPi (пин 1) |
| SIM900 | 5V | **2A пик** | Внешний БП (отдельно!) |
| WS2812B 8×8 | 5V | до 3.8A | Внешний БП (30% = ~0.7A) |

**Рекомендуемый БП:** 5V / 3A (один на всё устройство с запасом)

## /boot/config.txt — необходимые строки

```ini
# I2S (INMP441 + MAX98357 — полный дуплекс)
dtparam=i2s=on
dtoverlay=googlevoicehat-soundcard

# UART для SIM900 (GPIO14/15)
dtoverlay=disable-bt
enable_uart=1

# PWM для WS2812B (GPIO13)
core_freq=500
core_freq_min=500

# Камера
start_x=1
gpu_mem=128
```

## Проверочные команды после сборки

```bash
# Звуковые устройства
aplay -l && arecord -l
# → должна быть карта "googlevoicehat"

# UART
ls -la /dev/ttyS0
# → должен существовать

# Запись с INMP441 (3 сек) и прослушивание
arecord -D hw:0,0 -c2 -r16000 -f S32_LE -d3 /tmp/test.wav
aplay /tmp/test.wav

# Тест камеры
libcamera-hello --timeout 3000

# Тест всего железа
sudo python3 ~/oiynup/scripts/test_hardware.py --all
```
