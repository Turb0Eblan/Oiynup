# 5. Панель управления (panel.py)

Веб-приложение для управления устройством с Mac. Открывается в браузере.

## Запуск

```bash
python3 panel.py
# Автоматически открывает http://localhost:7777
```

**Зависимости** (устанавливаются автоматически):
```bash
pip3 install flask paramiko
```

---

## Вкладки

### 🔗 Подключение

| Элемент | Описание |
|---------|---------|
| Host / IPv6 | Адрес RPi. Для USB: `fe80::XXXX%en6`. Для WiFi: `10.55.0.1` |
| Пользователь | `oiynup` |
| Пароль | Пароль заданный в RPi Imager |
| **Подключиться** | Устанавливает SSH соединение |
| **Авто-поиск** | Находит RPi по mDNS (oiynup.local) |
| **Проверить всё** | Проверяет статус WiFi, USB, камеры, I2S, UART |

**Статус модулей:**
- ✓ OK — зелёный
- ✗ нет — красный (проблема с подключением или драйвером)

---

### 🚀 Деплой

| Кнопка | Действие |
|--------|---------|
| **Загрузить код** | tar + SSH, копирует весь проект на RPi |
| **Запустить** | `systemctl start oiynup` |
| **Остановить** | `systemctl stop oiynup` |

Прогресс-бар и лог показывают ход деплоя.

---

### 📷 Камера

| Кнопка | Действие |
|--------|---------|
| **Снять кадр** | Захватывает JPEG с RPi камеры и показывает в браузере |
| **Стрим** | 5 кадров подряд с интервалом 1.2 сек |
| **Сохранить** | Скачивает текущий кадр как `.jpg` |

---

### 🎤 Аудио

**Микрофон:**
| Кнопка | Действие |
|--------|---------|
| **Записать 3 сек** | Запись с INMP441, показывает уровень сигнала (0-100%) |
| **Воспроизвести** | Воспроизводит последнюю запись через MAX98357 |

Уровень сигнала:
- `< 5%` — микрофон не работает / тихо → красный
- `≥ 5%` — всё OK → зелёный

**Динамик:**
| Кнопка | Действие |
|--------|---------|
| **Произнести** | TTS через espeak-ng, текст из поля ввода |
| **Синус-тест** | 1 сек синус 1кГц через speaker-test |

---

### 📡 GSM

| Элемент | Описание |
|---------|---------|
| **Проверить сигнал** | AT+CSQ, показывает уровень 0-31 с полоской |
| Номер телефона | Номер для SMS (сохраняется в конфиге) |
| Текст SMS | Поддерживает кириллицу (UCS2 кодирование) |
| **Отправить SMS** | Отправляет через SIM900 по UART |

Уровень сигнала:
- `> 15` — хороший → зелёный
- `5-15` — слабый → жёлтый
- `< 5 / 99` — нет сигнала → красный

---

### 📋 Логи

| Кнопка | Действие |
|--------|---------|
| **Получить логи** | Последние 80 строк из journalctl |
| **Стрим** | Server-Sent Events, логи в реальном времени |
| **Стоп** | Остановить стрим |
| **Очистить** | Очистить окно |

Цветовая кодировка:
- 🔴 Красный — ERROR
- 🟡 Жёлтый — WARNING
- 🟢 Зелёный — OK / успех
- ⚫ Серый — информация

## Конфигурация

Настройки сохраняются в `.panel_config.json`:

```json
{
  "host":         "",
  "user":         "oiynup",
  "password":     "",
  "parent_phone": "+77001234567",
  "rpi_path":     "/home/oiynup/oiynup"
}
```

При следующем запуске поля заполняются автоматически.

## API эндпоинты

Panel работает как локальный Flask сервер. Все операции через POST `/api/`:

| Endpoint | Действие |
|----------|---------|
| `/api/connect` | SSH подключение |
| `/api/disconnect` | Отключение |
| `/api/discover` | mDNS поиск RPi |
| `/api/hw-check` | Проверка модулей |
| `/api/deploy` | Копирование кода |
| `/api/system-start` | Запуск сервиса |
| `/api/system-stop` | Остановка сервиса |
| `/api/cam-capture` | Кадр с камеры |
| `/api/mic-record` | Запись микрофона |
| `/api/mic-play` | Воспроизведение записи |
| `/api/speaker-speak` | TTS |
| `/api/speaker-sine` | Синус-тест |
| `/api/gsm-signal` | Уровень GSM |
| `/api/gsm-sms` | Отправить SMS |
| `/api/logs-fetch` | Получить логи |
| `/api/log-stream` | SSE стрим логов |
